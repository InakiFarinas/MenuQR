# MenuQR

Digital menu management system: React 19 + Tailwind CSS v4 + Vite 8.

**Stack**: restaurants → menus → categories → dishes  
**State**: All in App.jsx  
**Design**: Mobile-first, responsive

## Quick Start

```bash
npm install && npm run dev
```

- Public menu: http://localhost:5173/el-rincon-paisa
- Public menu (specific): http://localhost:5173/el-rincon-paisa/bebidas
- Admin panel: http://localhost:5173/admin/el-rincon-paisa
